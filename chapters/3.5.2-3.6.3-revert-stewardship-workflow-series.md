## Initial Mental Model

The 3.5.2 revert phase turns the 3.5 ledger/history work into a user-visible write-back capability. Product handoff says `revertToLedgerEntry` reconstructs prior state from the user-scoped ledger and writes corrective operations through server-apply with the existing Replicache/poke path. It is not a separate sync spine.

The 3.6 stewardship arc is a repo-preparation arc. It introduces `docs/tidy/*` as a support layer for source-of-truth maps, staleness audit, cleanup backlog, and ChatGPT / Claude Code / Codex support checklists. That folder supports existing owners; it must not become a second roadmap, design system, version oracle, or product handoff.

The 3.6.3 workflow realignment changes the intended AI operating model: ChatGPT is the second-opinion/docs-workflow auditor with scoped support writes; Claude Code is the future-plan architect and Codex-ready implementation explainer; Codex implements and reports automated validation evidence; the user/controller owns manual product validation and closeout.

The next phase, 3.6.4, is a decision/RFC phase for the Workspace OS pivot. It should define product nouns, current-to-target mapping, preserved invariants, migration risks, design implications, and non-goals before 4.0.0 begins runtime product-model work.
