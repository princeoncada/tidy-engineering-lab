# Implementation Mode Prompt

Implementation mode is separate from normal study mode.

It requires Prince to explicitly say `implementation mode`.

Before any implementation planning:

1. Read current product repo state.
2. Get local or git status evidence when relevant.
3. Define a narrow target.
4. Define the test plan.
5. Avoid broad edits.
6. Keep lab workflow separate from product changes.

Rules:

* The lab repo can document learning.
* Product repo changes require explicit instruction from Prince.
* Do not mix reading-mode study notes with product implementation commands.
