# Rebaseline Chapter Prompt

Use this when a newer product version changes an older study chapter.

Steps:

1. Read the chapter.
2. Read current product source documents fresh.
3. Identify which parts of the old mental model changed.
4. Add a rebaseline note instead of erasing old learning.
5. Update `ledgers/rebaseline-needed.md` if more work remains.
6. Update the latest handoff.

Rule: history stays visible. New understanding is added with evidence.
